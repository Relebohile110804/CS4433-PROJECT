Moderated LMS - version 1.1.0
=============================

Start the program
  Double-click lms.exe. A console window opens.
  The first time, it asks you to create the first administrator account.

Files the program creates in this folder
  lms.db           the database (all users, courses, assignments, marks and the audit log)
  submissions\     the files students hand in
  lms-errors.log   unexpected errors, with the time (send this file when reporting a problem)

Keep lms.exe, the .dll files and these three items together in one folder.
Make a backup regularly with Administrator > Backup and restore, and copy the
backup file to a USB drive or another computer.

The full installation guide and the user manuals are in the project report.
